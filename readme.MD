# NotebookLM Crie seu primeiro jogo 2D na Godot

Projeto no NotebookLM, um assistente voltado para o auxílio na criação do primeiro jogo 2D na engine Godot, especificamente da versão 4.1 pra frente, por algum motivo que desconheço não aceito links do site oficial da documentação da godot, mas está alimentando com pesquisas do deep research e diversos videos tutoriais do youtube.

> [🚀 Acesse o Assistente Aqui](https://notebooklm.google.com/notebook/09b1693d-773e-404c-bc2c-47909b93d0ce)

## 🧠 Diferenciais do Assistente

* Deep Research: Informações extraídas via pesquisas avançadas sobre as mudanças da Godot 4.
* Curadoria de Vídeos: Baseado nos melhores tutoriais e práticas do YouTube.
* Focado na Prática: Respostas diretas sobre GDScript e fluxo de trabalho 2D.
